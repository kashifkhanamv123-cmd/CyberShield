CyberShield: Interactive Cyber Attack and SOC Monitoring System

🛡️ Overview

CyberShield is an educational cybersecurity-focused web platform designed to demonstrate security concepts, cyber attack awareness, and SOC (Security Operations Center) monitoring functionalities in an interactive environment.

The project combines cybersecurity learning with practical web development by integrating authentication systems, monitoring dashboards, reporting modules, and awareness sections related to common cyber threats.

This platform was developed as a hands-on learning project to improve understanding of cybersecurity concepts, system organization, and security-focused application development.

---
🚀 Features

* 🔐 User Authentication System
* 📊 Admin Dashboard
* 🛡️ SOC Monitoring Concepts
* ⚠️ DDoS Awareness & Simulation Concepts
* 🎣 Phishing & Malware Awareness Sections
* 📝 Reporting & Feedback System

⚙️ Installation & Setup

✅ Requirements

Before running the project, make sure you have:

* PHP installed
* MySQL / MariaDB
* XAMPP, WAMP, or Laragon *(recommended for local setup)*
* A web browser

---
💻 Local Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/CyberShield.git
```

---

2️⃣ Move Project to Server Directory

For XAMPP:

```bash
htdocs/CyberShield
```

---

3️⃣ Import Database

* Open **phpMyAdmin**
* Create a new database
* Import the provided `.sql` file *(if included)*

---

4️⃣ Configure Database Connection

Update database credentials inside the configuration file:

```php
$db_host = "localhost";
$db_user = "root";
$db_pass = "";
$db_name = "cybershield";
```

---

5️⃣ Start Server

Start:

* Apache
* MySQL

using XAMPP/WAMP/Laragon.

---
 6️⃣ Open in Browser

```bash
http://localhost/CyberShield
```
